# Photoshop 可靠操作与脚本回退

## 已观察到的问题与证据

一次实际制作中，界面工具出现 `noWindowsAvailable`、屏幕尺寸为 `(0, 0)`、以及要求重新读取状态的提示。部分批量操作没有按预期生效，路径被追加到旧值，字号也未保留。输出 PSD 的标题层名称和 `layer.text` 已为“欢迎光临”，但边界为 `(0, 0, 0, 0)`，文字引擎的 `Editor.Text` 仍只有回车，Photoshop 画面和 PSD 合成图都没有标题。

这些证据说明要检查每个操作的结果，而不是把上述错误统一解释为“画布刷新延迟”或字体问题。具体底层原因未确认；不要将某种输入方法在所有 Photoshop 版本中都判定为失效。

## 界面操作：验证结果，限制重试

- 显示工具要求重新读取状态时，先读取最新 AX 状态；判断上一动作是否已经完成，避免重复点击、重复输入或重复保存。
- 截图后若使用 AX 索引，调用 `getAXState({disableDiffing:true})` 后重新定位控件。完整树的索引可能与上一份差异树不同。
- 路径、字号和缩放输入前确认选区。普通可编辑字段可用 `selectText` 或 `setValue`；不支持文本范围时，点选字段后读取选区状态，使用合适的键盘选择。确认字段值确实被替换，不能在旧路径或旧数字后直接追加。
- `super+a`、`typeText`、`paste` 或快捷键没有产生预期结果时，不重复假定它已成功。用菜单、控件动作或已授权脚本完成同一操作，并读取新状态。
- 模态窗口 AX 只显示“布局区域”时，可以依据当前截图或键盘焦点导航操作。坐标接口报 `noWindowsAvailable` 时，停止重复相同坐标点击。
- 同一步骤失败后只做一次状态刷新和针对性重试；仍失败时最多重新绑定一次应用，再检查结果。仍不可用就切换已授权的脚本路线，或报告具体阻碍并请求该路线的必要授权。不要在刷新、重绑、截图、点击之间无限循环。
- 打开辅助编辑器不等于 Photoshop 已收到剪贴板内容。仅为尝试绕开中文输入而反复启动其他应用通常没有收益；优先直接核对 Photoshop 文字引擎与实际渲染。

## 精确尺寸

先确定生成素材的实际尺寸，按比例缩放到足以覆盖目标画布的大小，再裁切到要求的像素尺寸。例如 1685×934 的素材按高 600 等比例缩放约为 1082×600，再居中裁切为 1080×600。不要通过取消比例约束来明显拉伸人物，也不要交付生成器的近似尺寸。

需要尽可能保留原图像素时，先建立目标画布，再将原始素材作为智能对象置入、等比例变换与裁切。已有画布仅作微量尺寸修正时，可采用图像大小加画布大小；视实际任务选择，不要求固定路线。

## 已授权的 Photoshop 脚本路线

使用 Photoshop 自身的 JSX/ExtendScript DOM 完成可编辑图层，不用外部栅格绘制替代 Photoshop 文字层。脚本写入本次 `work/`，采用绝对路径。启动执行前检查授权仍覆盖此次动作；使用 AppleScript/osascript 等桥接方式时也必须符合当前工具的明确授权要求。无需为同一授权范围再询问一次。

限定脚本操作对象：通过明确文件路径或新建文档的引用定位本任务文档，核对宽高与模式；不能只依赖 `activeDocument`，不能批量关闭用户文档，不能清空所有文字层。仅删除本任务创建并确认无用的空层，或重建明确指定的目标文字层。现有模板的其他图层、价格与文案保持原样。

创建标题的核心 DOM 操作如下（示意，执行时需补齐已检查的文档引用、实际字体和保存路径）：

```javascript
var title = doc.artLayers.add();
title.kind = LayerKind.TEXT;
title.name = '主标题 - 欢迎光临';
var t = title.textItem;
t.kind = TextType.POINTTEXT;
t.font = 'PingFangSC-Medium'; // 先确认此字体可用，其他语言/设计按实际字体选择
 t.size = UnitValue(88, 'pt');
t.contents = '\u6B22\u8FCE\u5149\u4E34';
t.position = [UnitValue(110, 'px'), UnitValue(317, 'px')];
var color = new SolidColor();
color.rgb.hexValue = 'A84C69';
t.color = color;
app.refresh();
```

字号、位置、颜色都按当前设计选择，此示例不限制其他广告布局。脚本文件需要稳定传递中日文时使用 Unicode 转义或经验证的编码；不要只修改 PSD 的文字描述字段而绕过 Photoshop 文字引擎。

保存 PSD 时使用 `PhotoshopSaveOptions` 并保留图层与颜色配置；PNG 以副本导出，不改变主 PSD 文档身份。脚本临时改变 `displayDialogs` 等应用状态时，在 `finally` 中恢复原值。保存后重新打开输出 PSD，读取真实文字内容，再进行视觉验收。发生异常时报告错误，保留文档和素材，不关闭未保存的用户内容。

## 文字验收与最终交付

成功必须同时满足：

1. 文案准确，存在可编辑文字层，预期可见的非空文字边界有面积。
2. Photoshop 画面、保存的 PSD 合成预览以及导出的 PNG 中能看到文案，字体、颜色、位置和换行正确。
3. 重新打开磁盘 PSD 后仍符合上述要求。PSD、PNG 的像素尺寸符合请求，文件非空。

使用 psd-tools 等只读库时，检查 `layer.kind`、`layer.text`、`layer.bbox`；解析器能可靠读取该 PSD 的文字引擎时，可辅助检查 `engine_dict['Editor']['Text']`。某些合法图层的数据形式不同，不把解析器的缺失信息直接判为 Photoshop 文件损坏。实际渲染和重新打开的结果决定是否交付。

若文本描述正确但边界为空、PNG 没有字，回到目标文字层，用已授权的 Photoshop DOM 设置真实 `textItem.contents` 并重建渲染，再保存验收。不要添加不可见文字层或仅把文字烘焙到背景上来通过检查。

可对比 PNG 与 PSD 合成图的一致性；不同颜色配置或导出设置可能造成轻微像素差异，应检查并解释实际原因，不一概要求逐像素完全一致。清除仅由本任务产生的空层与临时文稿，保留无关用户文档。最终只交付通过验收的 PSD 与 PNG，并说明人物/背景是否为一体栅格素材。
