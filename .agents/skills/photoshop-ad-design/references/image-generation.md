# Image2 与素材生成

用户偏好：新素材尽量使用 Image2（工具明确提供 `gpt-image-2` 时使用该模型标识）。这是优先项，不是所有任务都必须调用生成工具；已有素材、修改文字、制作料金表不必重新生成。

每次生成先检查当前工具参数和 imagegen skill，不把旧文档中的模型能力当作永远有效的事实。

## 选择生成方式

1. 优先使用内置 `image_gen`，不需要 API key。如果当前接口支持模型选择并明确提供 Image2，选择它。
2. 内置接口没有模型参数时，仍可按“尽量”偏好使用可用内置工具，不凭空添加 `model` 参数，不声称模型已确认。必要时在生成前用一句话说明当前无法指定或验证 Image2。
3. 用户明确要求保证 Image2，或明确选择 API/CLI 模型控制时，使用当前 imagegen skill 提供的正式 CLI/API 路线，读取其 CLI 与模型文档；不要编写临时 SDK 脚本绕过该路线。用户的模型偏好不代表要求付费 API，也不代表已配置 API key。
4. CLI/API 路线需要本地配置的 `OPENAI_API_KEY`。只检查是否存在，绝不输出密钥或要求用户在聊天里粘贴。缺少时说明该条件；“尽量 Image2”请求可继续内置方式，不为可选模型阻塞整项任务。明确指定必须 Image2 的请求则保留已完成设计，待指定路线可用。
5. 内置工具失败或缺失时，不自动改用收费 CLI/API；按 imagegen skill 要求取得该路线的授权。如果用户已明确选择该路线，无需重复询问。

## 尺寸与透明度

生成器支持的尺寸、比例和透明背景可能与最终 PSD 需求不同。依据实时接口或随工具提供的模型文档选择接近目标比例且有足够分辨率的素材，最终在 Photoshop 上建立精确画布、裁切和布局。不要为了生成尺寸约束把 1080×600 的最终交付改成另一尺寸。

如果 Image2 路线不支持透明输出，不添加不存在的透明参数。可以在 Photoshop 中使用选区和蒙版分离人物，或选择支持透明的内置工具并如实说明模型可验证性。换用其他明确模型前遵守 imagegen skill 的模型切换要求。

## 素材提示示例

用途：樱花主题网页 banner 的背景素材，最终画布 1080×600。
画面：春日樱花与一个可爱、衣着适龄的儿童角色。
风格：跟随用户网页或参考图；无参考时采用柔和粉色、清新插画。
构图：人物与文字区域互不遮挡，为“欢迎光临”预留干净空间；不要生成广告文案、logo 或水印。

若需要人物独立编辑，将上述拆成背景提示和独立人物提示，并保持色彩、光照和画风一致。文案在 Photoshop 中添加。
